## 📢 當前階段：提案週 (Proposal Week) 任務

本週為提案週，每位組員皆須透過專屬 HTML 模板提出構想，聚焦四大核心維度：
1. **美術風格**：視覺語言、色票與手繪幾何形狀
2. **美術風格可執行性**：如何用前端 SVG/CSS 穩定實現（拒絕純生圖畫風不可控風險）
3. **劇情與立意點**：5～7 分鐘故事情節，以及「為什麼需要這個劇情」
4. **劇情與美術搭配**：視覺光影與故事情緒的契合共鳴
