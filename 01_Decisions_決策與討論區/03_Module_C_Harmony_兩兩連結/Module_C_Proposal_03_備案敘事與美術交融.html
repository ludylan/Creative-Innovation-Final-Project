🤝 備案連結提案

【三大備案連結】形式突破、生態奇觀與尺度切換

🎭 備案一：破畫框 ✕ 畫布穿梭的實體衝突

• 敘事與技術咬合：一般動畫角色被困在鏡頭內，而本片直接將「瀏覽器畫布 (Canvas/SVG Box)」變成監獄。主角用手撕開網頁 DOM 邊界，跌入後方 CSS 代碼或不同渲染引擎的世界，讓「形式本身就是喜劇包袱」。

🌊 備案二：深海遷徙 ✕ 程序化暗光流體的生命連結

• 敘事與技術咬合：深海的巨大與孤獨，完全透過純前端「暗場光照計算（Additive Blending 與 Bloom 光暈）」來體現。主角的每一次微小游動，帶動周遭流體粒子微微發光，將「渺小生命在宏大系統中的相互依賴」轉化為極致唯美的視覺詩篇。

🌱 備案三：今天不開花 ✕ 鏡頭潛入的微距對比

• 敘事與技術咬合：利用相機推進（Camera Dolly Zoom）與遮罩轉場，只要一顆水滴滴入土壤，鏡頭瞬間無縫下潛至神秘的地下世界。外面的焦慮平淡與裡面的生機澎湃形成強烈節奏對比，工程難度收斂但情緒感染力極強。
