🎨 主案一美術提案

【主案一美術】極簡純線條 ➔ 震撼 3D 體積光影演變

🎨 代表風格：紙藝立體折疊 (Papercraft 3D)
實體紙張切邊、層疊視差、投射陰影，形式即內容（厚度阻礙）
🌟 開啟動態原型體驗

🖼️ 概念視覺對照：無厚度的二維 VS 實體厚度的三維

🎨 1. 起始風格：極簡二維（Minimalist 2D）

• 核心視覺：以最純淨的黑白線條、單色幾何色塊構圖。完全捨棄透視與景深，畫面如同乾淨的工程圖或幾何繪本。

• 技術實現：純 DOM SVG 向量，極輕量、加載瞬間完成，完全不用外部素材。

🏛️ 2. 三種 3D 世界的美術候選方向（供組員挑選）
風格選項 A

🔷 低多邊形折紙風 (Low-Poly 3D)

稜角分明的多面體世界，帶有水晶與幾何美感。前端 WebGL / Three.js 實踐門檻極低且效能極高。

風格選項 B

🧸 溫暖黏土體積感 (Claymation)

帶有溫柔的環境光遮蔽與厚重邊緣，讓物體看起來像實體玩具。金屬項鍊呈現啞光金色，最能強調「沉重物理感」。

風格選項 C

📖 景深立體紙雕書 (Pop-up Layers)

利用 CSS 3D 與分層紙板，像翻開一本立體童話書。雖然在 3D 空間，但材質依然保留紙張紋理，形成微妙交融。
