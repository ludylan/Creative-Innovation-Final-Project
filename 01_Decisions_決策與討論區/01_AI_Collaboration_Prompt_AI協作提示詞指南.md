## 📌 一、當前專案情況與背景提要 (Context & Background)

* **專案性質**：大學「創意與創新」期末專案（探索性科技 ✕ 藝術專案）。
* **作品形式**：打造約 **5～7 分鐘的「網頁繪本／視覺互動作品」**（純正片體驗，不剪輯幕後編碼過程）。
* **核心原則（重要聲明）**：
  * **以網頁前端技術（HTML / CSS / JavaScript / DOM SVG / Canvas / WebGL / WebGPU）驅動**。
  * **⚠️ 絕非純 AI 一鍵生成影片（如 Sora/Runway）！** 畫面圖層、動態與互動皆為前端代碼控制。
  * 製作過程中，AI 僅作為輔助工具（協助代碼編寫、生成音效配樂、或在極少數背景做輔助探索）。
* **技術與藝術開拓**：
  * 不拘泥於傳統 2D 手繪卡通動畫，積極探索 **GPU 即時場景渲染（Shader 光影、Three.js、動態粒子）**或生成式場景。
* **當前任務（提案週）**：
  * 全組採「模組化彈性提案」（可單獨提故事、單獨提美術、或提兩兩連結）。
  * 尚未決策內容：**劇情具體內容與立意點**、**具體要使用的網頁技術棧**、**美術風格定稿**。

## 🧠 二、AI 協作者角色與權限定位 (AI Co-Creation Philosophy)

在提案週中，**不必預設「人類一定要先有完整方案才能找 AI」**，AI 扮演雙向的「專案共同夥伴兼技術探路架構師」：

1. **若使用者毫無頭緒**：AI **主動拋出 3～4 個極具反差與前沿魅力的提案雛形**供組員挑選混搭。
2. **若使用者有初步狂想**：組員只需大膽妄想，AI 負責**實事求是查核前端生態與極限**（**嚴禁盲目捏造不存在的技術**）。
3. **把幻想轉化為前端現實**：提供圖層分拆、色票設定，並挖掘深層人文立意（回答「為什麼需要這個劇情？」）。
4. **檔案管理與報告收整**：AI 具備檔案架構整理能力，協助將共識收斂為符合期末報告規格的高品質提案文件。

## 📜 三、說故事級完整 AI 協作 Prompt 咒語

請組員直接將以下整段提示詞複製給 ChatGPT、Claude 或 Gemini。**不用刻意省 Token，把整件事情說得清清楚楚，AI 的回覆深度會大幅提升**：

```text
你好！我們目前正在進行一項大學「創意與創新」課程的期末專案。
專案的核心形式為：製作一部約 5～7 分鐘的「網頁繪本／視覺互動作品」。
我們有非常明確的硬性核心原則：整部作品必須由「網頁前端技術」（例如 HTML/CSS/JavaScript、DOM SVG 向量、HTML5 Canvas、或是利用 WebGL / WebGPU / Three.js 進行 GPU 即時渲染等）來完成，而不是使用 Sora、Runway 等純 AI 工具一鍵導出預先算好的死板影片。在過程中，我們可以運用 AI 作為輔助工具（例如協同撰寫代碼、生成音效配樂、或局部探索素材），但核心畫面與動態必須是程式可控、具備互動性的前端成果。

這是一部高度探索性的作品，形式不局限於傳統 2D 手繪卡通動畫，也可以大膽嘗試各類前沿視覺思路（例如：GPU 即時著色器渲染出的流動光影、幾何粒子世界、互動式網頁繪本、或多層次視差沉浸場景）。

現在，我們全組正在進行「提案週」，我需要你作為我的「專案共同夥伴兼技術探路架構師」：
--------------------------------------------------
【我的當前狀態】：
[情況 A] 如果我有初步點子：請在此描述你的點子、想做的視覺效果或故事狂想。
[情況 B] 如果我現在完全沒有想法：請直接寫「我現在毫無頭緒，請直接主動提出 3～4 個極具反差與前沿魅力的提案雛形讓我挑選！」
--------------------------------------------------

請你發揮主動引導權限，依照以下層次進行分析與產出：

【若我目前沒有具體想法】：
請不要反問！請直接主動設計 3～4 個不同風格的前沿提案（例如：一個 GPU 即時著色器渲染的深邃光影繪本、一個溫暖 2D 手繪貼紙風互動童話、一個生成式幾何粒子音訊繪本等），包含其故事概念、視覺方向與前端實現路線，引導我挑選或混搭。

【若我有提出想法，或在我選定方向後】：
第一點【實際技術可行性深度分析與檢索（嚴禁盲目捏造）】：
1. 請實事求是、深入檢視當前網頁前端技術生態（如 WebGL/WebGPU、Canvas 2D、SVG、CSS 動畫、GLSL Shader、或輕量動畫庫 GSAP/Pixi.js/Three.js 等）。
2. 這個構想在瀏覽器環境中是否真的完全可行？技術門檻與效能瓶頸（如移動端算力、瀏覽器相容性、GPU 記憶體開銷）在哪裡？
3. 有沒有現成的開源案例、類似技術範例（如 CodePen、GitHub 開源專案、Shadertoy、Three.js 官方範例）可以作為技術參照？
4. 如果遇到效能或技術瓶頸，有沒有合適的優化空間或降階落地方案？

第二點【前沿美術視覺風格與參考設定】：
1. 除了傳統動畫外，針對我的點子，有什麼驚豔的美術思路？（例如：手帳拼貼風、GPU 即時光影、低多邊形、極簡幾何、沉浸式粒子等）
2. 請提供具體的視覺風格關鍵字、主色調色票（含 HEX 色碼與象徵意涵），並說明畫面圖層（遠景、中景、前景、互動元件）在代碼中該如何分拆手刻。

第三點【劇情深度與核心立意點】：
1. 梳理一段約 5～7 分鐘的故事情節脈絡（開場 ➔ 探索發展 ➔ 氛圍轉折高潮 ➔ 餘韻結尾）。
2. 請深入探討：為什麼需要這段劇情？它的深層立意點、哲理寓意或情感核心是什麼？為什麼這個故事適合透過「網頁即時互動」來呈現給觀眾？

第四點【期末報告合規提案收斂與檔案輸出】：
請將上述發想與工程求證，收斂整理成一份邏輯嚴密、結構清晰的高品質分析提案，並告訴我該如何把它整合進期末專案 HTML 檔案中！
```
