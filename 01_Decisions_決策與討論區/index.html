📢 W10–W11 當前重要階段

期末專題提案週 (Proposal Week)

除了團隊協作之外，本週首要任務是收集每位組員的提案檔案。我們將每位成員的提案「模板化」，提供自由展示美術與可執行的互動空間，凝聚最終成品共識！

💡 為什麼我們需要「模板化提案」？

過去常發生組員直接把「與 AI 討論的落落長原始紀錄」全部丟上來，造成兩大痛點：資訊過多無從抓重點，以及天馬行空的內容在前端根本無法執行。
因此，本次提案週要求每位組員使用統一樣板，將點子收斂為具體、可落地的 HTML 提案頁，讓每個人都能放上自己的視覺／程式展示。

❌ 請避免的提案方式
  • 直接複製貼上整串未經整理的 AI 聊天紀錄
  • 只提抽象宏大的概念，卻不知如何在前端刻出
  • 劇情與美術完全脫節，缺乏視覺與程式評估
✅ 我們期待的模板化提案
  • 清楚指出為什麼需要這個劇情與其核心立意
  • 評估美術風格如何用前端 SVG/CSS 穩定落實
  • 在專屬 HTML 頁面內放上一張概念圖或簡易互動展示

📌 提案四大必填核心維度

請在您的個人 HTML 檔案中完整闡述：
🎨 1. 美術風格設定
視覺風格明確定位：
  • 線條、筆觸、色調與圖層規範
  • 建議之主色調色票清單
  • 角色幾何造形與視覺感受
⚙️ 2. 美術風格可執行性
落地工程評估（拒絕不可控）：
  • 如何用前端 SVG / CSS 手刻出來
  • 避免純生圖造成畫風分裂的對策
  • 團隊工時與技術門檻評估
📖 3. 劇情與立意點
故事核心價值（為什麼需要）：
  • 5～7 分鐘故事情節簡述
  • 為什麼需要這段劇情？立意是什麼？
  • 為何適合以網頁互動繪本呈現？
🤝 4. 劇情與美術搭配
視覺與文本的共鳴契合：
  • 畫風如何襯托劇情的哲理或氛圍
  • 日夜／光影轉變與情節高潮的連動
  • 互動節點對故事體驗的加分效果

🚀 如何填寫並提交您的提案？

1 點擊上方屬於您的「個人提案 HTML」檔案（或使用瀏覽器直接開啟）。
2 點擊頁面上的虛線文字區即可直接在瀏覽器打字編輯；也可以在原始碼中替換「展示區」為您的圖片或 SVG。
3 編輯完成後，點擊右下角「💾 下載儲存更新後的 HTML」，並 commit 推送至 GitHub（或傳給簡報組長彙整）。
