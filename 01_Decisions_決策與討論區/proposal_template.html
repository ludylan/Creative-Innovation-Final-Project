📖 01｜劇情故事與核心立意點 (Story & Rationale)
💡 思考方向：為什麼需要這個劇情？故事想傳達什麼哲理、寓意或情感？（拒絕為做而做）
📌 故事簡介（約 100~200 字）
請概述本片 5～7 分鐘的故事脈絡：主角是誰？他在什麼情境下出發？途中遇見了什麼問題？最後如何化解並收尾？
💡 為什麼需要這段劇情？立意點是什麼？
說明這段故事的意義（例如：探討成長與探索、科技與溫度的平衡、對日常微小事物的觀察等）。為什麼這段劇情適合用「互動繪本」的方式來呈現給觀眾？
🎨 02｜美術風格設定 (Art Style Specification)
💡 思考方向：視覺風格的關鍵字是什麼？線條、筆觸、幾何形狀如何規劃？
🖌️ 風格定位與視覺關鍵字
（範例：2D 手繪貼紙風、粗黑輪廓線 3.5px、童趣圓潤幾何、溫暖紙質底色、偏向幾何色塊堆疊而非複雜陰影渲染）
🌈 建議主色調色票（點擊文字可自訂色碼與說明）
#FDE68A 晨曦黃（溫暖希望）
#A8E6CF 薄荷綠（自然生機）
#A8D8F0 天空藍（遼闊遠景）
#FFCBA4 蜜桃橘（角色點綴）
⚙️ 03｜美術風格的可執行性評估 (Feasibility Analysis)
💡 思考方向：這套美術能不能用前端 SVG / CSS 手刻出來？有沒有過高的 AI 生圖不可控風險？工時大概多久？
💻 前端落實技術方式
• 角色與前景：採用純 SVG Path 向量繪製，便於用 CSS keyframes 製作呼吸、跳躍、視差等動畫。
• 背景景深：採用多層次 SVG 遠山、中景、近景，搭配滑鼠視差位移。
• AI 輔助界線：純手刻為主，僅在複雜紋理或特定背景時嘗試生圖後轉向量，避免純生圖造成畫風分裂。
⏱️ 工時與難度預估
預估角色造型繪製需要 X 天；場景 3 幕背景分層需要 Y 天；前端 CSS 動畫綁定需要 Z 天。整體落在團隊可控範圍內。
🤝 04｜劇情與美術的搭配 (Story & Art Harmony)
💡 思考方向：為什麼這個美術風格能襯托這個劇情？兩者如何互相加分？
✨ 搭配邏輯與共鳴點
說明當劇情進展到轉折或高潮時，美術光影、色調或動畫節奏要如何同步轉變。（例如：開場明亮清新，轉折時色系過渡到夜晚星空，配合主角心境的沉澱與突破。）
